# Hangman Game Project

## Overview

This project is a classic Hangman game implemented using HTML, CSS, and JavaScript. It utilizes DOM manipulation to create an interactive and engaging user experience.

## Features

- **Interactive Gameplay:** Users can guess letters to uncover a hidden word.
- **Scoring:** Track wins and losses.
- **Responsive Design:** Compatible with various screen sizes.
